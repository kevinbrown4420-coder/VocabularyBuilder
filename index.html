      Settings

      Your API keys are stored only in this browser's local storage. This app sends them to its own same-origin proxy, which immediately forwards the requested lookup to Merriam-Webster and does not intentionally save the key or response.

      Accessibility and navigation

      When enabled, the app header, main navigation, and footer are hidden only while a practice session is active. This reduces extra swipe targets without changing the question or feedback controls.

      Progress backup

      Backups contain your study progress and settings, but never your API keys.

      About the reference content

      Definitions are retrieved from Merriam-Webster's Collegiate® Dictionary with Audio. Synonyms and antonyms are retrieved from Merriam-Webster's Collegiate® Thesaurus. This personal study app is not endorsed by Merriam-Webster Inc.
